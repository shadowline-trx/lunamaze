# Luna Maze — Studio Site

The official studio website for **Luna Maze**, an independent product studio building tools at the intersection of cognition, focus, and craft.

Built with Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS, Framer Motion, and GSAP. Statically exported to `dist/` and deployed to GitHub Pages.

---

## Products

- **[AXIOM](https://lunamaze.com/axiom/)**: A calm, honest habit tracker and dopamine recovery companion grounded in neuroscience. Zero-knowledge privacy by design.
- **[Tether ADB](https://lunamaze.com/tether-adb/)**: Enterprise-grade Android device control center for Windows with wireless QR ADB pairing and screen mirroring.
- **[TypeCrt](https://lunamaze.com/typecrt/)**: Zero-latency typing test inspired by vintage CRT terminals.
- **[Drift](https://lunamaze.com/drift/)**: Handcrafted precision puzzle game exploring focus and calm design.

---

## Quick start

```bash
npm install
npm run dev          # http://localhost:3000  → Luna Maze landing
                     # http://localhost:3000/axiom/  → Axiom landing
npm run build        # static export to ./dist/
```

- **Next.js 16** (App Router, static export)
